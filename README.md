## What is THEROOT?

Central coordinator and infrastructure backbone for the V0 stack. Monitors all services, enforces norms and protocols, serves as the visual command center.

### Core Systems

| System | Description |
|---|---|
| **Service Monitor** | Real-time health checks across all V0 services |
| **Norm Engine** | 94 operational norms enforced at all levels |
| **Protocol Registry** | 91 active protocols auto-triggered on events |
| **LASU Sync** | Live, Auto, Sync, Update — all modules stay current |
| **Hardware Visualization** | 2.5D PC setup with temps, storage, USB |
| **Engine Index** | 14 engines tracked and coordinated |
| **Process Check** | Auto-kill duplicates, zombies, stale processes |
